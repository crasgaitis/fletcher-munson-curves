# fletcher-munson-curves

## course info
Electrical & Computer Engineering 520.445/645 <br/>
Audio Signal Processing <br/>
Fall, 2026 <br/>
Project 1 <br/>
Fletcher-Munson Curves of Equal Loudness <br/>

Objective:
1. Demonstrate understanding of Fletcher-Munson, i.e. equal-loudness curves (ELC)
2. Develop an ELC-based audio equalizer

## instructions
Make sure you have Python and Anaconda. <br/>
Run ```conda create -n 'fletcher_munson'```. Then, activate the environment via ```conda activate fletcher-munson``` and download the requirements.txt items via ```pip install -r requirements.txt```. <br/>
Run the app via ``` streamlit run main.py``` <br/>

<br/>
Alternatively, you can use the deployed web app via <a href = "https://what-the-fletch.streamlit.app/">what-the-fletch.streamlit.app.</a>
